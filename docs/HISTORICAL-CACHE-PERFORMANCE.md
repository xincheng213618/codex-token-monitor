# 跨天缓存补齐与周期分析响应

历史日志中的会话可跨天，复制的文件也可能保留旧修改时间，因此不能直接以目录日期或文件修改时间判断其中是否包含目标日期的数据。

`CodexLogFileIndex` 在成功完整读取后保存每个文件的 Token 记录最早/最晚时间。后续历史 Token、额度快照和区间扫描仍枚举日志文件，但会跳过内容时间范围与请求无交集、且文件校验信息未变化的文件。时间范围包含回放段，只用作保守筛选；模型、Fast 和子任务回放归因继续使用原解析器。

索引存放在 `%LOCALAPPDATA%\CodexTokenMonitor\codex-log-file-index-v1.json`，只保存文件路径、长度、创建/修改时间、首尾样本 SHA-256 和记录时间范围，不保存聊天内容。新增、追加、截断、替换或校验变化的文件重新读取；目标日期覆盖到的文件也完整读取，以保留上下文。索引不是持久化的逐字节追加游标。没有索引或索引损坏时回退完整扫描，清除缓存时一并删除索引。

只有成功读完且扫描前后文件状态一致时才更新索引；取消、不可读或扫描中变化不会成为成功的跳过依据。索引采用临时文件后替换，保存失败不影响已完成的统计读取。文件签名使用元数据和首尾样本，不提供针对任意中间内容篡改且保留全部元数据的完整文件认证。

首次升级后的索引建立仍需完整扫描。周期分析因此先独立读取已有缓存，在共享 I/O 锁被占用时也能展示图表和明细，并标明“缓存预览”。缓存预览不扫描来源日志、不持久化额度插值点、不训练或保存模型校准；完整查询随后沿用共享锁刷新，成功后替换预览。关闭窗口或退出程序仍会取消未完成的查询。
