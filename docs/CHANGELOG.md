# 变更记录

按日期分组的变更摘要（依据 git 提交历史，哈希可点击到对应提交）。版本号未做正式发布管理，这里按提交日期划分阶段。

## 2026-09-03

- 新增“数据管理 → 局域网共享”：本机可手动开启端口 36666 的被动服务，其他电脑通过地址和访问密钥手动上传本周数据、下载并合并服务器本周数据。
- 复用现有数据包去重与缓存写入，收到上传后刷新统计；增加本周范围校验、传输取消、超时、大小限制和并发忙碌提示。重启程序后不会自动开启服务。
- 框架依赖发布新增 ASP.NET Core 8 Runtime 要求；正式输出目录保持 outputs/CodexTokenMonitor。

## 2026-08-18

- Codex 数据包支持直接拖放到主窗口；识别 `*.codex.json` / `*.codex-data.json` 后先弹窗确认，再复用原有幂等合并流程。

## 2026-08-17

- DeepSeek V4 Flash / Pro 更新为正式峰谷价格，移除旧固定价及分离的“高峰 / 空闲”预设。
- 每条 token 事件按北京时间进入峰谷子汇总，最终在一个模型金额中合并计费；历史缓存自动回填高峰 token。

## 2026-08-14

- **新增 DSH 统计来源**：读取 DeepSeek Harness 会话日志（`~/.dsh/sessions/**/session.jsonl.zstd`，zstd 多帧拼接 JSONL，`ZstdSharp.Port` 解压），统计每次模型调用的 input / 缓存读取 / output / reasoning；新增 DSH 来源 Tab 与价格组（默认 DeepSeek V4 Pro 档），复用现有缓存/汇总/费用管线，后台预热自动覆盖。

## 2026-08-13

- 用量查询模块重构（`UsageModules`）：来源模块携带显示缓存（LRU 容量 8）、自定义起点与周期支持，切换来源时恢复各自状态（`34a807d`）。
- 明细行展示逻辑与前台刷新循环优化（`34a807d`）。

## 2026-08-05

- 实时日志增量读取加固（`LiveFileTailReader`）：支持“整批不提交”的按需重试读取，事件消费可中途拒绝并留待下轮（`bf50bf8`）。
- 额度周期识别容错：快照读取与 5h/7d 周期边界处理增强（`bf50bf8`）。

## 2026-07-22

- 数据导出支持范围选择：`仅导出今天 / 仅导出本周 / 导出全部`，今天与本周按北京时间计算（`abaae8c`）。

## 2026-07-19

- **数据管理**：新增跨电脑 Codex 数据导入/导出（`*.codex.json` 数据包），按稳定事件 ID 与额度快照键幂等合并；修复数据包命名与多设备导入（`fc1d30e`、`8461721`）。
- **额度实时读取**：通过本地 `codex app-server`（JSON-RPC `account/rateLimits/read`）读取 5h/7d 额度，自动发现 Codex CLI 副本（Desktop 插件、npm、PATH）；不可用时回退到会话日志（`fc1d30e`）。
- 时间轴图表增加轴标签与图例（`ee6a906`）。
- 后台缓存预热与显示性能相关更新（`7b59f82`）。

## 2026-07-13

- 移除遗留 WinForms 外壳，WPF 成为唯一主界面（`3db5835`，07-02 先行）。
