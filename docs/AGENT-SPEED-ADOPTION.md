# Agent Speed 能力接入与验收

本项目借鉴 [zoefix/agent-speed](https://github.com/zoefix/agent-speed/tree/a94a67fcc78e5d8eea5f82d8d5e737bccf994e2c)
的本地请求测速、解析与去重规则，审查版本为 `a94a67fcc78e5d8eea5f82d8d5e737bccf994e2c`。
MIT 许可与来源声明保存在 `docs/third-party/agent-speed`，发布包携带 `Notices/agent-speed`。

## 接入范围

| 能力 | 实现与验证 |
| --- | --- |
| .NET 10 | Core、WPF、测试、脚本及 CI 使用稳定 SDK；便携包自包含运行时 |
| 统一测速 | AgentSpeedEngine：区间加权、三秒实时窗口、在途估算、部分/最终用量更新、响应归属去重 |
| 七种来源 | Codex、Claude Code、DSH、WorkBuddy、ZCode、Kimi、Qoder 原生适配；没有有效起点的请求保留用量但不计实测速度 |
| 模式与指标 | 区分设置、回执、路由证据；输出速度与包含缓存输入的总吞吐量分别展示 |
| 峰值与会话 | 实测并行峰值、主子会话树、生成/工具/空闲状态及陈旧状态处理 |
| 持久历史 | AgentSpeedHistoryStore/Indexer：按日/来源/模型/模式汇总，文件签名及归属哈希去重、删除日志后保留贡献、CSV 导出 |
| 增量与只读 | 有界文件事件队列增量维护目录，正常监听五分钟补全扫描，监听不可用时局部五秒兜底、半行/压缩帧重试；ZCode 离线 WAL 在私有副本中重建 SHM，不在原库旁新增文件 |
| 生命周期 | 主采样独立于用量查询 gate；界面更新在 Dispatcher 上执行，关闭取消并排空读取、索引和监听器释放 |

费用、币种、额度周期、跨电脑数据共享沿用本项目的实现。网络排行榜、头像配对、系统流量服务、悬浮球及游戏化称号未接入。

## 界面与刷新

顶部采用无品牌图标的单行来源切换与工具栏，速度分析与数据管理同排，缓存状态位于底部。
左下实时并行速度持续更新，不依赖下方页签选择，遵守自动刷新开关。

用量趋势为独立模块；只有原下方列表区域在“用量明细 / 实时数据”之间等大切换。
页签位于同一白色容器的标题行，选中状态以文字颜色区分，不显示按钮式边框或底色。
外层保留一层 `12,10` 留白，两页内容为 0 Margin/Padding/BorderThickness，切换不改变趋势或分隔条高度。

实时数据页直接显示始终可见的五项速度指标，曲线在左，近期会话在最右窄栏。
RealtimeDataView 复用主采样器，不另开读取线程。隐藏时每秒只生成底部速度所需的轻量快照，不计算曲线、会话树或模型表；切入实时页时立即请求完整快照，即使自动刷新已暂停也会刷新一次。页面切换会取消并隔离旧采样结果，防止迟到的完整快照重新更新隐藏页面。
后台约每 30 秒单独计算并保存已观测峰值，不为持久峰值生成图表和会话列表。
完整速度分析窗口提供模型/模式与主子会话详情，历史与导出在该窗口内切换，可返回实时分析。

## 测量口径与边界

- 输出包含原生日志记录的推理 Token，请求耗时包含首字等待；平均值为总实测 Token 除以总请求耗时，不是逐响应平均值的算术平均。
- 耗时不足 0.5 秒按 0.5 秒计算；缺失起点、倒序或超过 15 分钟的请求不计实测平均，用量与请求数仍保留。
- 实时采用三秒窗口；估算只使用匹配来源、模型和模式的近期有效样本，完成后由实测校正。曲线由请求区间均摊重建，不等于逐 Token 到达时间。
- 日期固定 UTC+8，与主窗口用量范围分别标明。模式选择与实际服务回执分开标注，设置加速不能直接证明走了加速通道。
- 历史只持久化汇总、文件签名与归属哈希，不保存对话正文或原始逐请求行；已删除日志的贡献仍保留。损坏库先备份再重建，已删除日志仅在旧库备份中的统计不会凭空恢复。
- 历史峰值来自主采样或速度窗口计算并保存的来源峰值，缺少观测时显示缺失；不同来源的历史峰值不相加。速度历史暂不随原有数据共享同步。
- 上游黄金样例排除 .NET 日期范围之外的两个时间戳压力文件，不声称完整上游协议/数值边界兼容。压缩单帧上限 256 MiB，单行上限 32 MiB。

## 可复验检查

- Core：CodexSpeedTests、AgentSpeedNativeTests、AgentSpeedGoldenTests、AgentSpeedHistoryTests 覆盖原生协议、独立参考样例、流式更新、并行/模式、只读 WAL、历史复用/替换/取消/损坏恢复及 CSV。
- 桌面：`Scripts/Test-Desktop.ps1` 覆盖主窗口、设置、额度分析和速度四组。主窗口验证底部持续更新、隐藏时不生成图表/会话数据、暂停后切页仍生成一次完整快照、来源切换、趋势布局稳定、等大页切换、窄会话栏、最小尺寸速度可见和唯一分析窗口；速度组验证独立采样、估算校正、七来源、历史/导出、恢复和关停。
- 运行器：`Scripts/Test-DesktopRunner.ps1 -IncludeProbeCli` 检查报告真实性、产物哈希、隔离、超时和 CLI 参数拒绝。
